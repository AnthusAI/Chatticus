# Names and metaphors

**Date:** 2026-09-04  
**Anthus frame:** Babulus = campaign factory; Chattic.us = agent/bot farm with specialized desks. Public news desk covering the category = **Agent Zoo** (not a name for the workplace). Chatticus picture of the shared place = **reactor chamber**.

This page is the **internal vocabulary record**. Product dossiers stay on [product pages](index.md). The public encyclopedia on chattic.us is idea-led and must not grow a page per competitor — see [Public encyclopedia vs this tree](public-encyclopedia.md).

## What is being named

The layer above one agent and one turn: named persistent workers, a shared environment, coordination, and governance. Chatticus's working picture is a **reactor chamber** — a durable place where agents collaborate and do useful work.

The public site splits that from journalism:

- **Agent Zoo** — the *desk* that covers the category (dated posts).
- **Public wiki** — *idea* pages (workplace, farm, factory-as-idea, shared computer).
- **This Kanbus tree** — *products*, overlap, freshness.

Do not rename Chatticus bots, the computer, skills, routines, or the worker protocol after third-party coinages (Grok Bots, Droids, Gas Town rigs, Crews).

## Software factory / agent factory

**What people mean.** SDLC as a production line: signals → triage → plan → build → test → review → ship → monitor → signals again. Agents are stations; humans design the line and own outcomes. Distinct from one coding-agent loop.

**Concrete products.** [Factory 2.0](products/factory-20.md) (Factory.ai; docs: [Software Factory overview](https://docs.factory.ai/software-factory/overview)); Warp Factories, Vercel eve, Uber/Mastra/Encore essays (adjacent language, not all peers). Gas Town's "Wish Factory" is a role in a coding city, not the Factory.ai product.

**Overlap with Chatticus.** High metaphor / medium product. Same farm-the-org instinct; skills/automations/missions ≈ skills/routines; human governance. Factory skews enterprise software engineering.

**Claim / avoid / redefine.** Acknowledge adjacency; **do not own "software factory."** That brand is Factory.ai's + eng-blog zeitgeist. Prefer **agent farm / office / organization** in Chatticus voice. If speaking to eng buyers, say Chatticus can *host desks that participate in* a software factory, not that Chatticus *is* one. Public wiki: one idea page about the production-line *idea*, not a Factory.ai homepage.

See [Software factories](categories/software-factories.md).

## Bot farm / agent farm

**What people mean.** Many concurrent agents producing work around the clock; throughput over single-assistant polish. Chattic.us already uses "24/7 agent farm." Internal Anthus: Chattic.us = bot farm; Babulus = campaign factory.

**Concrete usage.** Chatticus marketing; Anthus ops docs; Yegge fleet / polecats; Factory Missions; Devin fleet of agents (coding).

**Overlap.** Core self-description. Maps to [Multi-desk farms](categories/multi-desk-farms.md) plus [Shared-computer bot teams](categories/shared-computer-bot-teams.md).

**Claim / avoid / redefine.** Claim **agent farm** in public copy. **"Bot farm" still echoes spam/click-fraud** — use it internally if the Anthus frame needs it; prefer **agent farm** on chattic.us. Pair with **specialized desks** so it does not read as undifferentiated swarm. Keep Babulus as the **campaign factory** so farm ≠ factory in the Anthus stack.

## Model zoo

**What people mean.** Classic ML: catalog of pretrained model weights (Caffe Model Zoo, Hugging Face hub). **Not** a multi-agent workplace. Model selection/routing is a separate ops concern. Sometimes loosely used for "a bunch of agents"; that usage is a collision.

**Overlap.** Low / none for product positioning. **Agent Zoo** (the news desk) is a different word on purpose; do not let public copy call the desk or the product a model zoo.

**Claim / avoid / redefine.** **Avoid** as a name for the workplace or the product. If Anthus needs the catalog idea, say **model roster / routing policy**, not zoo.

## Reactor chamber

**What people mean.** Chatticus-internal picture: a confined, stable place where agents collaborate and do useful work. Not an industry SEO term.

**Claim / avoid / redefine.** Fine in participant voice and on the public **agent workplace** idea page. Do not treat it as a category label buyers already search for. Do not build a product feature named reactor chamber.

## Adjacent — not the workplace noun

These show up in the same conversations. They are usually **runtime**, **harness**, **control plane**, or **one-agent execution**.

| Name | Why it is adjacent | Kanbus home |
| --- | --- | --- |
| **Agent harness** | Tool loop + memory + sandbox around *one* agent | [Coding-org orchestrators](categories/coding-org-orchestrators.md), [Cursor Cloud Agents](products/cursor-cloud-agents.md) |
| **Agent runtime / agent OS** | Execution or memory substrate, not roster + shared computer | [Always-on personal agents](categories/always-on-personal-agents.md) |
| **Control plane** | Dispatch and governance above runtimes (e.g. builderz-labs Mission Control — homonym with an unrelated "Mission Control AI") | [Coordination substrates](categories/coordination-substrates.md) |
| **Cloud Agents / cloud environment** | Cursor: task VMs and machine images | [Cursor Cloud Agents](products/cursor-cloud-agents.md) |
| **Droid Computer** | Factory: persistent slot for a Droid, not the factory floor | [Factory 2.0](products/factory-20.md) |
| **Cowork / Operator** | Single acting computer-use agent | [Acting single coworkers](categories/acting-single-coworkers.md), [Claude Cowork](products/claude-cowork.md), [OpenAI Operator](products/openai-operator.md) |
| **Swarm / hive / colony** | Often task fan-out or unrelated products | Avoid as Chatticus category voice |

## Collisions — same word, different thing

| Name | Usual meaning | Do |
| --- | --- | --- |
| **Model zoo** | Pretrained weight catalog | Avoid for workplace / desk / product |
| **Bot farm** | Spam, click fraud | Prefer **agent farm** in public |
| **Foundry** / **AI Foundry** | Azure/Microsoft model platform ("AI app and agent factory") | Disambiguate; do not unqualified |
| **Studio** | Playground / builder UI | Not a workplace noun |
| **Agent factory** | Verint CX product; Microsoft tagline | Not our category name |
| **Mission Control** | builderz-labs control plane vs Mission Control AI synthetic labor | Homonym; say which |

**Yard** (shipyard) and **shop floor** remain weak in primary sources. Fine as color, not as a label we try to own.

## Coordination substrate (related metaphor)

How desks share state — versioned board + gossip (Kanbus) vs Beads sync vs plans-in-repo blackboard — is a differentiator watch, more than "who has an LLM."

See [Coordination substrates](categories/coordination-substrates.md). Public wiki does not need a Kanbus-vs-Beads page.

## Editor shortlist

**Public Chatticus voice (ideas, not product rename):** agent workplace, agent farm, specialized desks, office, reactor chamber (participant color). Software factory as an *idea we cover*, not a name we own.

**Avoid in public category voice:** model zoo, unqualified bot farm, unqualified foundry, studio, harness/runtime/agent OS as the name of the product, swarm/hive as the name of the farm.

**Internal Anthus:** Chattic.us = bot/agent farm; Babulus = campaign factory; keep those distinct.
