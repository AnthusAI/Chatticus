# Metaphors — factory, farm, zoo

**Date:** 2026-09-04  
**Anthus frame:** Babulus = campaign factory; Chattic.us = bot farm; specialized desks, not generalists.

## Software factory / agent factory

**What people mean.** SDLC as a production line: signals → triage → plan → build → test → review → ship → monitor → signals again. Agents are stations; humans design the line and own outcomes. Distinct from one coding-agent loop.

**Concrete products.** [Factory 2.0](products/factory-20.md) (Factory.ai); Warp Factories, Vercel eve, Uber/Mastra/Encore essays (adjacent language, not all peers).

**Overlap with Chatticus.** High metaphor / medium product. Same farm-the-org instinct; skills/automations/missions ≈ skills/routines; human governance. Factory skews enterprise software engineering.

**Claim / avoid / redefine.** Acknowledge adjacency; **do not own "software factory."** That brand is Factory.ai's + eng-blog zeitgeist. Prefer **bot farm / office / organization**. If speaking to eng buyers, say Chatticus can *host desks that participate in* a software factory, not that Chatticus *is* one.

See [Software factories](categories/software-factories.md).

## Bot farm / agent farm

**What people mean.** Many concurrent agents producing work around the clock; throughput over single-assistant polish. Chattic.us already uses "24/7 agent farm." Internal Anthus: Chattic.us = bot farm; Babulus = campaign factory.

**Concrete usage.** Chatticus marketing; Anthus ops docs; Yegge fleet / polecats; Factory Missions; Devin fleet of agents (coding).

**Overlap.** Core self-description.

**Claim / avoid / redefine.** Claim "agent farm" / "bot farm" carefully. Prefer **agent farm** in public copy: "bot farm" still echoes spam/abuse. Pair with **specialized desks** so it does not read as undifferentiated swarm. Keep Babulus as the **campaign factory** so farm ≠ factory in the Anthus stack.

See [Multi-desk farms](categories/multi-desk-farms.md), [Shared-computer bot teams](categories/shared-computer-bot-teams.md).

## Model zoo

**What people mean.** Classic ML: catalog of pretrained model weights (Caffe Model Zoo, community zoos). **Not** a multi-agent workplace. Model selection/routing is a separate ops concern.

**Overlap.** Low / none for product positioning.

**Claim / avoid / redefine.** **Avoid.** Wrong category; confuses buyers. If Anthus needs the idea, say **model roster / routing policy**, not zoo.

## Coordination substrate (related metaphor)

How desks share state — versioned board + gossip (Kanbus) vs Beads sync vs plans-in-repo blackboard — is a differentiator watch, more than "who has an LLM."

See [Coordination substrates](categories/coordination-substrates.md).
