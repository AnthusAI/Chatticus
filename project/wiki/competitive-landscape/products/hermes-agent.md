# Hermes Agent

Nous OSS persistent personal agent: memory, skills, cron, multi-channel gateway on *your* server. One agent grows with you — not a named multi-bot farm.

## What it is / who for

Self-hosters (Yang noted for scheduled jobs on Mac Mini). Free OSS (MIT); model costs separate. Released Feb 2026.

## Overlap with Chatticus

**Med–High** on routines, memory, self-host continuity. Low on multi-bot shared office product UX.

## Differentiation

Hermes: single persistent personal agent. Chatticus: specialized desks, shared computer, approvals as product, multi-human room.
