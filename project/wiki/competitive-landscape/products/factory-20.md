# Factory 2.0

Enterprise software factory from Factory.ai: Droids, Automations, Droid Computers, Missions — model independence and sovereign intelligence framing for SDLC production lines.

## What it is / who for

Enterprise software engineering orgs. Customers named in announcement materials include NVIDIA, EY, Adobe, Palo Alto Networks, Adyen, Blackstone, Wipro, Comarch (per Factory post). Software Factory docs noted as Private Preview in Anthus scout.

## Overlap with Chatticus

**High metaphor / medium product.** Same "farm the org, not one chat" instinct; skills/automations/missions ≈ skills/routines; human governance. Skews enterprise software engineering, not household office.

## Differentiation

Factory owns the "software factory" brand. Chatticus should acknowledge adjacency and prefer bot farm / office / specialized desks. Chatticus can host desks that participate in a software factory; it is not positioned as one. Pricing: contact / enterprise.
