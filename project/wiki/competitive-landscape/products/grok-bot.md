# Grok Bot

Durable named AI teammates on one user-scoped persistent cloud computer (browser, FS, terminal), with plugins/MCP, skills, routines, and approvals.

## What it is / who for

Individuals on Cursor Pro+ / Ultra / Teams or SuperGrok Plus/Heavy (per FAQ); Teams included; Enterprise enablement + admin controls. Thin clients (desktop + mobile); work runs in Cursor cloud Firecracker microVM.

## Overlap with Chatticus

**High.** Named persistent bots; one shared computer per user (not per bot); separate screens; skills = how, routines = when; approvals / Auto Review; background work with laptop closed; connectors preferred, computer-use fallback; bot-to-bot handoffs. Near architectural twin — differentiate deliberately, do not describe Chatticus as a clone.

## Differentiation

**They have / Chatticus doesn't (yet):** GA desktop+mobile UX, plugin marketplace, teach-by-demonstration, Cursor Cloud Agent delegation, enterprise Network Controls / Team Setup / Action Recording, distribution via Cursor/xAI.

**Chatticus positioned / they don't emphasize:** MIT + run-in-your-AWS / no lock-in; organization / office / farm as primary brand (not Cursor coding orbit); household v1 framing; Anthus managed-service adjacency.

**Trust notes (Yang, 2026-09-02):** Deleting a bot does not remove shared-computer files/sessions; Reset Agent Computer = recovery, not privacy wipe. Trust = access granted, not brand.
