# Microsoft Scout

M365 Autopilot always-on personal agent; **powered by OpenClaw**. Desktop agent with files/shell/browser + sub-agents (Frontier program notes in research).

## What it is / who for

Microsoft 365 users. Productization of OpenClaw rather than a sibling farm. Pricing: M365 (unverified here). Multi-desk confidence: Med–High on shared computer; **Low** on multi-named org farm (one Scout + sub-agents).

## Overlap with Chatticus

**Medium.** Scout's desktop computer-use is closer to Chatticus *computer* than Agentforce; not a multi-named desk org.

## Differentiation

One Autopilot agent (+ sub-agents) in M365 vs Chatticus specialized multi-desk farm. Copilot Studio covers enterprise multi-agent orchestration separately.
