# Zo Computer

Personal AI cloud computer / always-on workspace. One personal cloud computer + agent; adjacent computer metaphor, not a multi-named-bot authority system / enterprise digital workforce farm.

## What it is / who for

Individuals wanting a personal always-on AI cloud computer. Trial then paid. Live since ~2025-06.

## Overlap with Chatticus

**Med–High** (computer, 24/7). Lower on multi-named desks with org authority/approvals as product.

## Differentiation

Zo: personal cloud computer + agent. Chatticus: multi-bot farm with specialized desks, shared workplace authority, multi-human path.
