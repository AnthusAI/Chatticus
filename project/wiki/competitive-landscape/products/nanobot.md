# nanobot

Self-hosted personal AI agent runtime with gateway `--background`. Runtime, not an office product.

## What it is / who for

Developers/self-hosters wanting a personal agent runtime. OSS.

## Overlap with Chatticus

**Medium.** Always-on personal runtime adjacency; not multi-bot shared office.

## Differentiation

Runtime layer vs Chatticus productized farm/office. Crowded self-host lane with OpenClaw/Hermes/ZeroClaw.
