# Beads

Dolt-backed / git-ledger issue graph for agents — work-tracking backbone used by Gas Town / Wheelhouse. Open tool for agent-oriented issue dependencies and sync.

## What it is / who for

Coding-org operators and multi-agent harness authors who want a syncable issue graph (docs cite active versions; DoltLite Beta related stress work). Not a full workplace product.

## Overlap with Chatticus

**Medium (substrate peer).** Powerful for coding orgs. Kanbus docs argue sync/daemon friction and monolithic JSONL conflicts. Chatticus steering treats Kanbus (files + gossip) as the Anthus-shaped alternative — watch as integration/choice, not as an external product competitor.

## Differentiation

Beads: agent issue graph with sync semantics. Kanbus: one file per issue; git = truth; gossip + overlay for realtime. Differentiator watch is how desks share state.
