# Cursor Cloud Agents

Isolated cloud VMs for coding tasks → PRs (formerly Background Agents). Grok Bot can delegate here. Coding PR workers on ephemeral task VMs — not a multi-bot office product by themselves.

## What it is / who for

Cursor users running async coding agents that produce pull requests. Part of the Cursor/xAI stack alongside [Grok Bot](grok-bot.md).

## Overlap with Chatticus

**Medium** (shared with Grok stack). Ephemeral coding workers vs Chatticus persistent named desks on one shared computer.

## Differentiation

Task VMs for code/PRs vs persistent office/farm with non-coding desks and ownership story. Pricing: Cursor usage.
