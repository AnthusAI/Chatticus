# Amazon Bedrock Agents

Managed multi-agent collaboration (supervisor/routing) on Amazon Bedrock; AgentCore runtime for any framework + A2A/MCP. Infra/platform, not desk UX.

## What it is / who for

AWS builders deploying multi-agent systems on Bedrock. Farm confidence: Med (infra, not desks). Adept founders/tech reverse-acqui-hired to Amazon 2024 — treat Adept as historical / non-peer, not a live multi-desk SaaS peer.

## Overlap with Chatticus

**Medium (infra).** Supervisor/routing patterns converge with Agentforce MAO / Kore / CrewAI. Not a Chatticus-shaped office product.

## Differentiation

Cloud infra multi-agent vs productized farm/office. Chatticus customer-owned AWS option is complementary narrative (run Chatticus on AWS) rather than competing with Bedrock Agents as a peer UX.
