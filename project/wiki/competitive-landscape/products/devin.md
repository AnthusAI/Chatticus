# Devin

Autonomous software engineer / org-delegated coding agents from Cognition. "AI employee" and fleet-of-agents framing for software work.

## What it is / who for

Engineering orgs delegating coding work to autonomous agents. Coding-only. Entry pricing ~$20/mo + ACU cited in third-party 2026 reviews (verify on vendor).

## Overlap with Chatticus

**Medium** (fleet, async). Not a multi-desk household/office product; coding-only AI employee.

## Differentiation

Devin: coding AI employee. Chatticus: multi-desk farm across domains, shared workplace, approvals beyond code merge. "Just use Slack + Devin" is one competitive kill-list alternative to watch.
