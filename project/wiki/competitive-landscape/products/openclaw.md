# OpenClaw

Self-hosted always-on personal agent gateway (name history: Warelay → … → OpenClaw). Foundation path; not a multi-bot shared office product.

## What it is / who for

Individuals wanting a self-hosted always-on personal agent runtime on their machine. Single personal runtime lineage. Microsoft Scout is a productization of OpenClaw in M365.

## Overlap with Chatticus

**Medium** (always-on, machine continuity). Low on multi-bot office / named desk farm.

## Differentiation

OpenClaw: one personal daemon/gateway. Chatticus: multi-human + multi-bot shared room with authority. Self-host always-on is crowded — do not compete as "another Mac Mini agent."
