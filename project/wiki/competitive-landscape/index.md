## Executive map — where Chatticus sits

Chatticus sits in the emerging **human + named bots in a shared workplace** lane — not chat-only, not a coding IDE, not a one-shot Operator. Positioning on chattic.us: shared spaces for people and bots; office metaphor; persistent named bots; one shared computer (files / browser / terminal) with separate screens; skills (how) + routines (when) + approvals; work that outlasts the laptop; v1 personal/household, multi-tenant later; MIT + customer-owned AWS option. Also described as a 24/7 agent farm.

| Shape | Closest product / pattern | Overlap |
| --- | --- | --- |
| Named bots + shared cloud computer + skills/routines/approvals | [Grok Bot](products/grok-bot.md) | Highest — near architectural twin |
| End-to-end SDLC software factory | [Factory 2.0](products/factory-20.md) | High on farm/org metaphor; coding-enterprise skew |
| Coding-org orchestrator / city of roles | [Gas Town / Wheelhouse](products/gas-town-wheelhouse.md) | High on specialized roles + work graph; DIY/bespoke |
| Always-on personal agent on your machine | [OpenClaw](products/openclaw.md) / [Hermes](products/hermes-agent.md) | Med–high on continuity; low on multi-bot office |
| Single acting coworker in product/Slack | [PostHog](products/posthog.md) | Med — acting agent, not a farm of desks |
| Enterprise digital labor / AI workforce | [Salesforce Agentforce](products/salesforce-agentforce.md), [Atomicwork](products/atomicwork.md), [ServiceNow Autonomous Workforce](products/servicenow-autonomous-workforce.md) | High on org vocabulary; CRM/ITSM-bound |
| Campaign / outbound production factory | [Babulus](products/babulus.md) (Anthus) | Complementary |

**White space.** Few products combine (1) multi-named teammates, (2) one shared workplace with authority/approvals, (3) non-coding household/ops work, (4) customer-owned infra / MIT, and (5) specialized desks rather than one generalist.

Steer messaging toward **org + farm + control**, not another chat agent. See [Metaphors](metaphors.md) for claim / avoid / redefine guidance.
