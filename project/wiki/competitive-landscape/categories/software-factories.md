# Software factories

## What this category means

End-to-end **SDLC as a production line**: signals → plan → build → test → review → ship → monitor. Agents as stations; humans design the line. Brand and product language dominated by Factory.ai Factory 2.0 and eng-blog zeitgeist.

## Why it matters for Chatticus

High metaphor adjacency ("farm the org, not one chat") but coding-enterprise skew. **Do not own "software factory"** — prefer bot farm / office / specialized desks. Chatticus can host desks that participate in a software factory; it is not positioned as one. Babulus remains the Anthus **campaign factory**.
