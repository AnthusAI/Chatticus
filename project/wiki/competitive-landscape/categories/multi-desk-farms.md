# Multi-desk farms

## What this category means

Products that present **multiple named persistent bots/teammates with roles** (specialized desks), a shared workplace or shared tools/context, and humans collaborating with authority/approvals — framed as an office, farm, or organization rather than one chatbot.

Match criteria used in research:
1. Multiple named persistent agents with roles
2. Shared workplace / computer / tools / files (or strong shared context)
3. Humans + bots with authority/approvals
4. Office / farm / organization framing

## Why it matters for Chatticus

This is Chatticus's primary shape. Closest peers prove the vocabulary ("digital workforce," "AI coworkers," "hire a roster") is mainstream; Chatticus differentiates on **shared computer + specialized desks + ownership (MIT / customer AWS)** rather than CRM/ITSM-bound labor alone.
