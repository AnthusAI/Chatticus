# Always-on personal agents

## What this category means

Self-hosted or cloud **always-on personal agents** — persistent memory, skills, cron/routines, multi-channel gateways — typically one agent growing with you on *your* machine or a vendor cloud, not a multi-bot shared office.

Crowded: OpenClaw lineage, Hermes, nanobot, ZeroClaw, Gemini Spark, Microsoft Scout (OpenClaw-powered), Instinct, etc.

## Why it matters for Chatticus

Med–high overlap on continuity and routines; **low** on multi-bot office. Chatticus wins if the pitch is **multi-human + multi-bot shared room with authority**, not "another daemon on a Mac Mini."
