An **agent workplace** is where persistent, named agents hold jobs, share tools (often a computer), run in the background, and hand work to each other. Chatticus pictures it as a **reactor chamber**: stable infrastructure for collaboration, not a single chat session or model catalog.

The industry has not settled on one word for this layer. Software factory, workspace manager, command center, crew, and a dozen metaphors all name overlapping slices. For a sourced map of who says what—and which terms collide with model zoos, bot farms, and Azure Foundry—see [Names for the workplace](names-for-the-workplace.md).
