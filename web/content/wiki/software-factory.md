A **software factory** is an assembly line whose product is merged code. The happy path looks like: a ticket or spec goes in; agents plan, implement, test, and open a review; a human (or a policy) merges.

That is a real, useful picture. It is not the same picture as an [agent workplace](/wiki/agent-workplace). A workplace can *contain* a factory. A factory does not automatically give you a household computer, a bookkeeper, or a farm of non-coding desks.

## Why the words get borrowed

"Factory" is the strongest industrial metaphor in circulation for agents that ship software. Vendors use it as a product name. Commentators use it for any multi-agent coding setup. The result is that "software factory" now names both an **idea** (this page) and several **products** (internal landscape notes, not here).

Chatticus does not need to own the phrase. We need to be able to say: we are building a workplace; a software factory is one kind of work that workplace can take on, not the definition of the product.
