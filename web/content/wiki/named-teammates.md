A **named teammate** is a bot that stays itself across turns: a name, a role, memory, and a seat on the organization's roster. People address it. Other bots on the channel can read what it wrote. Only the addressed bot acts.

That is a different idea from a **pool**. A pool hands the next task to whoever is free. The worker has no biography. It is also different from an **acting coworker**: one human-shaped agent that plays intern, pair, or employee in a single thread.

Named teammates need an [agent workplace](/wiki/agent-workplace) they can return to. Without a durable computer and a shared transcript, "persistent" is just a longer context window.

## Why names matter

Names are how humans delegate ("ask Pax to file that") and how bots stay specialized. A farm of desks only works if the copywriter is not also the bookkeeper by accident. See [farms and desks](/wiki/farms-and-desks).

Names are also how you *don't* get a swarm. Swarm pictures optimize for throughput. Teammate pictures optimize for accountability: this bot did this work, in this channel, on this computer.
