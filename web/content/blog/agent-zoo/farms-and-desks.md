A software factory is an assembly line whose product is merged code. A ticket goes in. Agents plan, implement, test, and open a review. A human or a policy merges. That is a real, useful picture. Vendors use the phrase as a product name. Commentators use it for any multi-agent coding setup.

Chatticus is a farm of desks. Copy, books, research, ops. Each desk is a named teammate with memory and a beat. The desks share one Linux computer. Factories optimize a delivery pipeline. Farms optimize a roster of ongoing work.

Enterprise digital labor sells a workforce you hire. Always-on companions sell availability in a sidebar. Those sit next to this category. A companion can remember you and still have nowhere to put a long-running job. A factory can ship software and still have no bookkeeper.

We do not need to own the word factory. We need to be able to say: we are building a workplace; a software factory is one kind of work that workplace can take on. When Factory, Grok Bot, Gas Town, or the next coinage ships something that changes how a farm runs, it belongs in a dated post on this desk.

If you only remember one distinction from these first notes: a farm is who sits where, a factory is how code gets merged. Chatticus is the farm.
