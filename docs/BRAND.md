# Chatticus brand system

## Direction

Chatticus is a quiet room full of living teammates. The interface is editorial,
calm, and controlled; animation belongs to the teammates and the work they are
doing. The brand should feel like an organization with presence, not a generic
AI dashboard.

The public promise remains: **Build the AI organization you control.**

## Visual language

- Warm paper is the default field. Near-black ink carries structure and type.
- Signal green marks active work and primary actions. Clay marks approvals and
  other moments that need human attention.
- Vultus is the avatar runtime and model-zoo contract, not a single canonical
  face. It can host procedural, Lottie, and later audited Rive models behind one
  state vocabulary.
- Character silhouettes make roles legible before labels do: the Editor is a
  compact reviewing capsule, the Reporter carries a microphone and radar, the
  Copy Writer is built from a page and flowing lines, and the Illustrator is a
  diamond-shaped maker with a brush gesture.
- Layouts use strong asymmetry, large editorial type, fine rules, and generous
  negative space. Avatars interrupt the grid instead of living in generic
  dashboard cards.

Display copy uses Newsreader. Interface copy uses Manrope. State labels,
permissions, and technical proof use IBM Plex Mono.

## Motion grammar

- Neutral teammates are almost still, with occasional character-specific
  micro-movements.
- Thinking, tool use, speaking, and completion share semantic state names while
  each model interprets those states in its own choreography.
- The creative-desk models gather facts, draft copy, draw, and edit with visibly
  different props, silhouettes, and loops.
- Completion is brief and confident.
- Approval uses clay and stops. It never celebrates before a person decides.

Essential state is always present in text. Reduced-motion users receive static
avatars, immediate content, and no decorative transforms.

The original procedural Vultus face remains a compatibility model. It is not
the brand, and it is not the default visual answer for every role.

## Intellectual-property boundary

The `bloub` project demonstrates useful state-driven animation principles, but
its own license notice says the MIT license covers its code rather than the
xAI design it imitates. Chatticus does not reuse that silhouette, eye geometry,
state choreography, or branding.

No third-party Rive or Lottie character ships without a recorded creator,
source URL, license, download date, modification note, attribution surface,
and separate review of embedded fonts, audio, logos, and other outside rights.
